# Which visual treatment makes setup, practice, and review self-explanatory?

Type: prototype
Status: open

## Question

Create a small, disposable phone-first visual prototype of the three core states: place the camera, practice with one cue, and review a squat still or basketball path. Explore two purposeful setup illustrations and one coherent icon/type/color treatment; compare the result against the current screenshots and real camera-framing constraints. Decide which design makes the next action and tracking uncertainty clearest from a distance.
